# 0018 — Let topic pages draw their content from the guide, by any means

- **Status:** Accepted
- **Date:** 2026-10-30
- **Supersedes:** [0007-hand-written-topic-pages](0007-hand-written-topic-pages.md)

---

## Context

[ADR 0007](0007-hand-written-topic-pages.md) said each topic page is written
by hand, and the site never reads the guide Markdown. It was provisional:
Javier wasn't sure, and it left a hybrid open for a section worth embedding
exactly. The Harness Engineering page now needs one. It shows the twelve
heuristics from the guide word for word, and its graph nodes use the guide's
part epigraphs. Copying that text by hand only creates drift.

There is also a longer-term direction. Javier supplies the guide as Markdown,
and an agent summarizes it and generates the page content, following the
visual patterns the site is establishing now. 0007's "by hand" rule stands
in the way of that.

## Decision

A topic page's content is not required to be written by hand. It can be
written by hand, taken from the guide Markdown (verbatim where the guide's
wording is the point), or generated by an agent from the guide. Whatever its
source, a page follows the design system and the shell, and the usual checks
decide whether it ships. The guide stays the source of truth for the facts
and wording it contains.

This ADR does not build a generation pipeline. That comes later, with its
own ADR once its shape is clear. For now, pages are still authored as Astro
pages, and nothing in the build reads the guide.

## Alternatives considered

- **Keep 0007 and retype the heuristics:** the rule stays simple, but
  retyped text drifts from the guide.
- **Allow only embedded sections (the hybrid in 0007):** solves today's need
  but would be superseded again once generation starts.
- **Decide the generation model now:** the visual patterns it should follow
  aren't settled yet, so any design would be guesswork.

## Consequences

- **Positive:** pages can reuse the guide's wording exactly, and the way is
  open to generating pages from guide sources.
- **Negative:** no rule now says where a page's text came from. Briefs have
  to name the source of every piece of user-facing text, as the readiness
  rule already requires.
- **Neutral:** the guide and a page can still drift where a page paraphrases.
  Only verbatim reuse is tied to the source.
