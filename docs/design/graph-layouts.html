Topic graph layout: force-directed vs fixed

A · Force-directed

The layout is computed by a force simulation; each topic then glides out from the centre to its place, and the graph keeps breathing gently. Hover a node, or drag one and watch the rest react.

B · Fixed positions

Each node has a designed position, identical on every load and screen. The same motion plays: nodes fade in, links draw in.

Design exploration for the landing brief's "Layout" question. Links are placeholders (every topic joined to a hub) until "Edges" is decided. One topic is shown live only to show its look.
