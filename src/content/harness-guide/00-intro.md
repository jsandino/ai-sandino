# A Practical Guide to Harness Engineering

*Python-flavored. Project-agnostic. Opinionated where it matters.*

---

## What this guide is

A working reference for engineers building software with AI coding agents — Claude Code, Cursor, Aider, Codex, or whatever comes next. It distills the discipline of *harness engineering* — designing the environment around an agent so it produces reliable, maintainable software at scale — into patterns you can apply project-by-project.

The guide assumes Python tooling for examples (Ruff, pytest, pre-commit) but the principles apply to any stack. It assumes you have a working AI coding agent and have written code with it; it does not teach prompt engineering or model selection.

## What this guide is not

- A list of prompts to copy-paste
- A defense or critique of AI coding agents as a category
- A reference for any specific model, vendor, or product feature set
- A replacement for reading code

## How to use it

Read [Heuristics](./02-heuristics.md) first. It's one page. The rest of the guide expands on those twelve ideas, and you should be able to come back to that page and recognize every line as a compressed version of something you now understand.

Read Part I to get the mental model. After that, the parts are independent — read in order, or jump to whichever section matches the harness work you're about to do.
